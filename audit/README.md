# Literature audit of reporting practice

| File | Contents |
|---|---|
| `AUDIT_PROTOCOL.md` | Inclusion criteria, coding items and rules, fixed before coding; change log |
| `CODER_INSTRUCTIONS.md` | The coding manual given to the second coder |
| `SEARCH_LOG.md` | Search queries and candidates |
| `STRATUM_B_FRAME.csv` | External sampling frame (studies included in Lima & Gondim 2026) and their coding status |
| `audit_codes.py`, `compare_coders.py`, `tally.py` | Controlled code list, inter-coder agreement, final counts |

| `AUDIT_FINAL_CODES.csv` | Final (resolved) codes of the 24 included studies, with both coders' codes before resolution |
| `coding/` | Both coders' sheets with a quotation for every code: coder 1 (`coder1_sheet.xlsx`); coder 2, first 20 studies (`coder2_sheet_20_studies.xlsx`) and the 4 studies coded last, re-coded by hand with the coder's declaration and the resolution of the five resulting disagreements (`coder2_sheet_4_studies_recoded.xlsx`); the resolution workbook for the first 20 studies (`resolution_20_studies.xlsx`). Files prefixed `SUPERSEDED_` are the discarded earlier coding of the four studies, for which an AI assistant had drafted the codes, and its resolution; they are kept for transparency and are not used. |

P13 was excluded on verification (Preprints.org; the protocol admits only peer-reviewed and arXiv papers); it remains in the coding sheets but not in the final codes.
